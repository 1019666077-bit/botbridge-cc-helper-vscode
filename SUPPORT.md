# Support

Thanks for using **Bot Bridge CC Helper** (VS Code extension).

## Where to get help

- **Issues / bug reports (this extension):** <https://github.com/1019666077-bit/botbridge-cc-helper-vscode/issues>
- **Homepage / download the desktop Helper:** <https://botbridge.dev/cc-helper>
- **Email:** moying.studio@outlook.com

When reporting a problem, please include:

- Your VS Code version (**Help → About**).
- Your OS.
- The output of **Bot Bridge CC Helper: Check Environment** (Command Palette →
  *Bot Bridge CC Helper: Check Environment*).

## Scope

This repository is the free, MIT-licensed **VS Code extension** only. It is the
bridge: it detects a local install, opens its inbox, dispatches jobs and connects
agent mode over MCP.

It does **not** include, and cannot support:

- The Windows tray/daemon, the realtime progress panel, or the installer — these
  are the **desktop Helper**, sold separately at <https://botbridge.dev/cc-helper>.
- Pro features: hard token/budget caps, stall timeout, Bark/webhook push.
- The Claude Code CLI itself.

The Cursor / Grok Bot plugin with the same playbook lives at
<https://github.com/1019666077-bit/cc-helper-plugin>.
